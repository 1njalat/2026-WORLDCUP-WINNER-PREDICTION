# 🏆 2026 FIFA World Cup Winner Prediction

Predicting the winner of the 2026 FIFA World Cup using historical match and team performance data sourced from Kaggle.

---

## 📌 Project Overview

This machine learning project analyzes historical FIFA World Cup data spanning from **1970 to 2026** across **49 competing countries** to forecast match outcomes and tournament progression. 

> **Key Milestone:** The model successfully predicted **all 4 semifinalists** for the 2026 FIFA World Cup.

---

## 📊 Dataset Highlights

- **Source:** [Kaggle](https://www.kaggle.com/)
- **Timeframe:** 1970 – 2026
- **Scope:** Historical match statistics, team ratings, and historical performance metrics across 49 national teams.

---

## 🛠️ Data Pipeline & Methodology

1. **Data Preprocessing & Cleaning:** Handling missing values, standardizing team identifiers, and aligning historical match records.
2. **Feature Engineering:** Extracting head-to-head records, recent form, goal differentials, and tournament experience.
3. **Model Development:** Training classification and regression models to estimate match win probabilities and knockout stage progression.
4. **Evaluation:** Validating predictive accuracy against actual 2026 tournament results.
